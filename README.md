# Ridhil — AI Content Creator & Visual Storyteller Portfolio

A modern portfolio website showcasing high-quality AI-generated content, cinematic video production, prompt engineering, digital branding, and creative storytelling.

## 🚀 Live Demo & Capabilities
- **Commercial Showcases**: Cinematic AI commercials, automotive visuals, high-fashion editorials, and digital art.
- **Interactive Prompt Inspector & Playground**: Explore real prompt engineering workflows and generation parameters.
- **Executive Light & Midnight Slate Modes**: Seamless theme switching with 4 custom accent colors.
- **Custom Portrait Upload**: 1-click personal portrait customizer with local browser persistence.
- **Fully Responsive**: Optimized for ultra-fast performance across all screen sizes and mobile devices.

## 🛠️ Tech Stack
- **Frontend**: Semantic HTML5, Vanilla JavaScript (ES6+), Modern CSS3
- **Styling**: Tailwind CSS & Custom Theme Variables
- **Icons**: Handcrafted & Lucide SVG Icons
- **Fonts**: Plus Jakarta Sans, Syne, Space Grotesk, Inter, JetBrains Mono

## 📂 Project Structure
```
ridhil-portfolio/
├── assets/                  # Studio images, project showcases & portraits
├── index.html               # Main portfolio markup & sections

├── script.js                # Theme switcher, filters, modals & uploaders

└── README.md                # Project documentation
```
